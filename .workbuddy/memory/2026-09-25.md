## 排查：测评页弹出 "e.find is not a function"

- 报错来源：生产包被压缩，某个变量（压缩后为 `e`）不是数组却调用了 `.find()`，被全局 toast（`App.jsx` notify）捕获显示。
- 用 Node 实测 V8 报错文案确定调用点形态：只有「接收者是单个变量」才会是 `e.find is not a function`；
  `data.answers?.find` → `e.answers?.find is not a function`；`(rows||[]).find` → `(...).find is not a function`；
  `block.split("\n").find` → `e.split is not a function`。据此排除了 api.js SSE 解析与 ResultPage。
- 答题链路（AssessmentPages.jsx send → api.js chat → handleEvent）中没有任何 `.find`，所以异常不是答题链路自身抛出。
- 最可能的点：`Shell.jsx:29` `classApi.joined().then((items) => { setClasses(items); items.find(...) })`，
  其 catch 正好是 `notify?.(error, "error")`，失败时清空班级列表但不白屏。
- 根因机制：`api.js` `request()` 中 `response.json()` 失败会兜成 `{ message: "服务返回了无法解析的内容" }`，
  且 `!response.ok` 为 false、`body.code` 为空时不抛错，直接 `return body.data ?? body` —— 对象被当成数组返回。
  触发场景：nginx SPA 兜底返回 index.html、网关 HTML 错误页、后端重启中返回空体（状态码仍是 200）。
